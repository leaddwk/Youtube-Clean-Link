# 스토어 등록 문구

## 이름

클린 링크 for YouTube™

## 짧은 설명

YouTube™ 영상 링크의 추적 인자를 공유·복사·열기 전에 정리하고 시작 시간은 유지합니다.

## 상세 설명

영상을 공유할 때 필요한 주소만 전달하세요.

클린 링크는 YouTube™ 영상 URL의 불필요한 인자를 정리합니다. 공유 창에 보이는 주소, 복사되는 링크, 받은 링크를 여는 과정에 적용되며 시작 시간은 유지합니다.

주요 기능

• 공유 창의 주소 입력칸에서 `si` 등의 불필요한 인자를 제거합니다.
• 시작 시간을 지정하면 `https://youtu.be/영상ID?t=107`처럼 시간 값이 남습니다.
• 공유 창의 시작 시간 체크를 해제하면 시간 값도 주소에서 사라집니다.
• 받은 링크를 이 확장이 설치된 Chrome에서 열면 등록된 추적 인자를 YouTube 요청 전에 제거합니다.
• 메시지·Facebook·WhatsApp 등 지원되는 공유 버튼에 넘기는 YouTube 주소를 정리합니다.
• 확장 버튼을 눌러 현재 탭의 주소를 확인하거나 링크를 직접 붙여 넣어 정리·복사할 수 있습니다.

개인정보와 권한

링크는 기기 안에서 처리합니다. 개발자 서버에 방문 기록이나 링크를 수집·전송하지 않으며 광고·분석 SDK를 포함하지 않습니다. 자동 정리에 필요한 YouTube 도메인 권한만 요청하며 클립보드를 읽어 감시하지 않습니다. 자세한 로컬 데이터 처리 범위는 개인정보처리방침에서 확인할 수 있습니다.

지원 범위

Chrome 111 이상, youtube.com·youtu.be·youtube-nocookie.com의 지원되는 URL에 적용됩니다. 받은 링크의 요청 전 제거는 등록된 추적 키를 대상으로 하며 임의의 모든 식별자를 제거하는 기능은 아닙니다. 일반 영상·재생목록 주소의 식별 값은 유지하고, 짧은 공유 링크와 Shorts·Live 공유 링크는 `t`만 유지합니다. 소셜 서비스가 자체적으로 추가하는 식별자는 이 기능의 대상이 아닙니다.

URL 정리는 로그인·쿠키·IP 주소·시청 기록에 의한 정보 처리를 차단하거나 완전한 익명성을 제공하지 않습니다. 모바일 YouTube 앱과 다른 브라우저에는 적용되지 않습니다. 웹사이트 구조가 변경되면 일부 공유 버튼의 대응이 달라질 수 있습니다.

독립 개발한 확장으로, Google 또는 YouTube가 제작·후원·보증하지 않습니다. YouTube는 Google LLC의 상표입니다.
