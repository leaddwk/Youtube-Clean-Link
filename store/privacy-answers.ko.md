# 개인정보 및 권한 입력 자료

기준: 1.1.1 소스. 실제 업로드한 버전과 아래 내용이 같은지 확인한 뒤 대시보드에 입력합니다.

## 단일 목적

YouTube 영상 링크에서 불필요한 URL 인자를 공유·복사·열기 전에 기기 안에서 제거하고, 시작 시간 등 필요한 값을 유지하는 것입니다.

## activeTab 사용 이유

사용자가 확장 버튼을 눌렀을 때 현재 활성 탭 URL을 읽어 팝업에 표시하고 정리된 주소를 제시합니다. 전체 탭 목록이나 방문 기록을 수집하지 않습니다. 사용자의 명시적인 확장 실행에만 사용합니다.

## clipboardWrite 사용 이유

사용자가 팝업의 복사 버튼을 누르면 정리된 URL을 클립보드에 씁니다. 클립보드를 읽지 않고, 백그라운드에서 클립보드 내용을 감시하지 않습니다.

## declarativeNetRequestWithHostAccess 사용 이유

외부에서 받은 YouTube 링크를 포함하여 YouTube 도메인으로 향하는 문서·프레임 GET 요청에서 알려진 추적 인자를 서버 요청 전에 제거합니다. 정적 규칙의 queryTransform.removeParams만 사용하며 시간·영상·재생목록 인자는 제거하지 않습니다. 광고 차단이나 응답 본문 수집에 사용하지 않습니다.

## 호스트 권한 사용 이유

`*://*.youtube.com/*`, `*://youtu.be/*`, `*://*.youtube-nocookie.com/*`에서 공유 창의 URL·페이지 링크·복사/공유 데이터를 로컬에서 정리하고, 해당 도메인의 문서·프레임 요청에 정적 제거 규칙을 적용합니다. 임베드의 관련 프레임에도 적용합니다. 외부 메시지·SNS 사이트나 전체 웹사이트에 대한 읽기 권한은 요청하지 않습니다.

## 원격 코드

원격 코드를 사용하지 않음. 실행되는 JavaScript와 요청 규칙은 전부 제출 ZIP 안에 포함됩니다. 외부 스크립트, CDN, eval, new Function, 동적 원격 import, 분석 SDK를 사용하지 않습니다.

## 데이터 처리 공개

**서버 수집이 없다는 이유로 데이터에 전혀 접근하지 않는다고 표시하지 마세요.** Chrome 정책은 기기 내부에서만 처리하는 경우도 공개하도록 안내합니다.

- 웹 기록/탐색 URL: 사용자가 실행한 팝업의 현재 탭 URL과 YouTube 문서 요청 URL을 로컬에서만 처리합니다. 기록을 축적하거나 외부 전송하지 않습니다.
- 웹사이트 콘텐츠: YouTube 페이지 링크, 공유 입력값, 사용자가 복사·공유하는 텍스트/HTML 안의 URL을 로컬에서만 처리합니다. 메시지함·주소록을 수집하지 않습니다.
- 식별·결제·건강·위치·인증 정보의 수집, 광고 목적 추적, 활동 로그 저장은 구현되어 있지 않습니다.

대시보드가 접근·이용까지 포함한 데이터 유형을 묻는 항목에서는 **웹 기록**과 **웹사이트 콘텐츠**에 해당하는 로컬 처리를 공개하고, 위 범위와 개인정보처리방침을 일치시키세요. 현재 대시보드의 정확한 문구와 정의에 맞춰 선택합니다. 처리하지 않는 종류를 추가로 선택하지 않습니다.

이 버전은 데이터를 판매하거나, 단일 목적과 관계없는 목적으로 이용·제공하거나, 신용/대출 판단에 이용하지 않습니다. 개발자 본인이 실제 운영도 이 선언과 일치함을 확인한 뒤 데이터 사용 인증란을 체크합니다.
